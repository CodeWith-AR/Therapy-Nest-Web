Privacy By Architecture

Zero Cloud Voice Transmission. 100% On-Device Processing.

Unlike commercial apps that stream private medical voice recordings to expensive cloud APIs, Therapy Nest runs a pre-trained 50MB Vosk acoustic model directly on the user's phone.

  • ✓
    Complete Patient Privacy: Microphone audio is processed entirely in volatile device RAM and discarded immediately. No voice data is ever recorded to a server.
  • ✓
    Full Offline Continuity: Rural and underserved patients can practice indefinitely with zero internet access using Drift SQLite local caching.
  • ✓
    Optimized for Budget Devices: Engineered to run smoothly on 2GB-RAM Android devices without thermal throttling or high battery consumption.
speech_pipeline_offline.dart 
// 1. Capture microphone PCM stream locally
final audioPath = await recorder.stop();

// 2. Transcribe on-device via Vosk (0ms latency, $0 API cost)
final transcript = await voskService.recognize(audioPath);

// 3. Compute phoneme similarity against target
final score = JaroWinkler.similarity(transcript, targetWord);

// 4. Update patient ability estimate (θ) via IRT locally
localDb.updateTheta(domain: 'speech', score: score);
Item Response Theory (IRT)

Dynamic Difficulty Matching to the 75% Flow Channel

Traditional therapy apps use crude static levels. Therapy Nest utilizes a 2-Parameter Logistic (2PL) IRT and Elo adaptive engine that updates the patient's latent ability (θ) after every single attempt.

By matching item difficulty (b) to the patient's ability (θ), the app keeps success rates at approximately 75% — proven by clinical literature to maximize neuroplastic recovery while preventing discouragement.
